## Tools used

The team used **OpenAI Codex** and **Google Gemini** for coding assistance. Codex also assisted with debugging, interface refinement, test development, documentation organization, and drafting explanations in this repository. The team confirmed Gemini's use for coding; this disclosure does not attribute particular files or tasks to Gemini where no detailed record is available.

AI assistance is part of the development process, not independent scientific review. Contributors remain responsible for checking the implementation, sources, behavior, and claims.

A [machine-readable disclosure](ai-disclosure.json) accompanies this document.

## Scientific data are separate

Scientific observation pixels originate in SPHEREx archive FITS products from NASA/IPAC IRSA. Catalog references originate in SIMBAD. The app can compute cutouts, registration, masks, display stretches, and measurement diagnostics from those products. These are processing operations, not generated replacement observations.

Archive outages, masked pixels, missing coverage, or incompatible comparisons must remain visible. The project does not synthesize substitute science images after a failed request.
